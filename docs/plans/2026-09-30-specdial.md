# Plan: specdial

**Goal:** the harness, task set and data for the design in
`docs/specs/2026-09-30-specdial.md`: 900 agent runs across 5 functions, 4 spec
levels and 3 agents, scored by behaviour signature, with `analyze.py` printing
every number the post will quote.

**Architecture:** per-function task dirs under `tasks/`; `evaluate.ts` turns one
implementation plus a corpus into a canonical output vector; `check_tasks.py`
refuses any task that breaks the rules before money is spent; `run.sh` (ported
from `../interview-signal/run.sh`) runs one agent session per container and
copies out `impl.ts`; `score.py` runs `evaluate.ts` over every run inside the
same image with no network; `analyze.py` computes the metrics. Mirrors mutgap
and interview-signal in layout and style.

## Ground Rules

- Repo: `specdial/`, branch `master`. Node
  v24, npm, Python 3 standard library only, bash with `set -uo pipefail`.
- Every process pins `TZ=UTC`.
- Commit messages: sentence-case imperative summary, no type prefix, for
  example `Add the behaviour evaluator`. No `Co-Authored-By`, no "Generated
  with" line, no AI attribution of any kind. Stage only the task's Touches
  paths, never `git add -A`.
- No em dashes in prose, comments or docs.
- Functions (task dir name = exported name): `parseEnv`, `toCsv`,
  `globToRegex`, `safeFilename`, `formatDuration`. Source for each:
  `../mutgap/corpus/<name>/`.
- Levels: `L0`, `L1`, `L2`, `L3`. Agents: `sonnet`, `opus`, `codex`. Reps
  `1` to `15`. Run id: `<fn>__<level>__<agent>__r<rep>`, run dir
  `runs/<run id>/`.
- Files per task dir `tasks/<fn>/`: `reference.ts`, `buggy.ts`, `stub.ts`,
  `spec.md`, `meta.json` (copied from mutgap), `ticket.md`,
  `examples.test.ts`, `properties.test.ts`, `gen.ts`, `corpus.json`.
- What the agent's work dir holds, per level (cumulative):
  - L0: `package.json`, `node_modules` (symlink to the image's preinstalled
    deps), `src/<fn>.ts` (copy of `stub.ts`), `TICKET.md` (copy of `ticket.md`)
  - L1: + `src/<fn>.test.ts` (copy of `examples.test.ts`)
  - L2: + `SPEC.md` (copy of `spec.md`)
  - L3: + `src/<fn>.properties.test.ts` (copy of `properties.test.ts`)
- Visible test files import from `./<fn>` (for example
  `import { parseEnv } from "./parseEnv"`), so they run unchanged in the work
  dir. In the task dir they are run against `reference.ts` or `stub.ts` by
  copying into a temp dir under those names.
- Prompts, literal, with `<fn>` substituted:
  - L0: ``Implement `<fn>` in `src/<fn>.ts`. The request is in `TICKET.md`.``
  - L1: ``Implement `<fn>` in `src/<fn>.ts`. The request is in `TICKET.md`, and `src/<fn>.test.ts` has tests it must pass. `npx vitest run` runs them.``
  - L2: ``Implement `<fn>` in `src/<fn>.ts`. The request is in `TICKET.md`, the full specification is in `SPEC.md`, and `src/<fn>.test.ts` has tests it must pass. `npx vitest run` runs them.``
  - L3: ``Implement `<fn>` in `src/<fn>.ts`. The request is in `TICKET.md`, the full specification is in `SPEC.md`, and `src/<fn>.test.ts` and `src/<fn>.properties.test.ts` have tests it must pass. `npx vitest run` runs them.``
- Per run caps: `--max-budget-usd 1.00` for Claude, 600 s wall clock for all.
- Corpus format, `tasks/<fn>/corpus.json`:
  ```json
  {"function": "parseEnv",
   "inputs": [{"id": "h001", "category": "quoted-value", "args": ["A=\"x\""]},
              {"id": "g0001", "category": "generated", "args": ["..."]}]}
  ```
  Hand-written ids `h001`..; generated ids `g0001`..`g0500`. An argument that
  is `undefined` is written `{"$undefined": true}`. For `globToRegex` every
  input also carries `"probe": [<path strings>]`.
- Canonical output per input, as written by `evaluate.ts`:
  - returned value: `{"ok": <canon>}`; thrown: `"THROW"`; over 1000 ms:
    `"TIMEOUT"`
  - `<canon>`: JSON with object keys sorted; `undefined` as
    `{"$undefined": true}`; `-0`, `NaN`, `Infinity`, `-Infinity` as
    `{"$num": "-0"}` etc.; a `RegExp` result, when the input has `probe`, as
    the array of `regex.test(path)` booleans in probe order (a fresh
    `RegExp(source, flags)` per path so `g`/`y` state cannot leak), and
    without `probe` as `{"$regex": source, "flags": flags}`.
- Signature hash: sha256 hex of the UTF-8 `JSON.stringify` of the outputs
  array.
